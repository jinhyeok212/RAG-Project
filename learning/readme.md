# Learning

이 디렉터리는 팀 프로젝트를 시작하기 전에 **RAG(Retrieval-Augmented Generation)의 기본 개념과 전체 실행 흐름을 이해하기 위해 진행한 실습 코드**를 보관하는 공간입니다.

> **주의**
>
> 이 디렉터리의 코드는 학습 및 구조 파악을 목적으로 작성되었으며, 프로젝트의 공식 Baseline이나 최종 구현이 아닙니다.

---

## 학습 목표

* RAG의 전체 처리 과정 이해
* 문서 전처리 및 청킹 과정 학습
* 임베딩 생성 및 벡터 데이터베이스 구축 과정 이해
* 사용자 질문과 관련 문서를 검색하는 과정 이해
* 프로젝트 구현 전 RAG 파이프라인과 파일 구조 파악

---

## RAG 학습 흐름

```text
원본 데이터
    ↓
문서 전처리
    ↓
청킹(Chunking)
    ↓
임베딩 생성
    ↓
벡터 데이터베이스 저장
    ↓
사용자 질문 입력
    ↓
질문 임베딩 생성
    ↓
유사 문서 검색(Top-k)
    ↓
검색 결과 확인
```

※ 일부 실습은 RAG의 검색(Retrieval) 과정 이해를 목적으로 진행했기 때문에 답변 생성(Generation)은 포함되지 않을 수 있습니다.
