# Vector DB 검색 평가 작업 계획

> **전체 흐름**  
> Vector DB 전달받기 → 설정 확인 → 평가 질문 로드 → 질문 임베딩 → Top-1·3·5 검색 → 검색 결과 저장 → 정답 청크 확인 → 검색 시간 정리 → 평가 담당자에게 전달

## 1. Vector DB 정상 작동 확인

- [ ] Vector DB가 정상적으로 불러와지는지 확인
- [ ] 저장된 전체 청크 수 확인
- [ ] 임의의 질문으로 검색 테스트
- [ ] 검색 결과에 다음 필드가 반환되는지 확인
  - `chunk_id`
  - `document_id`
  - 거리 또는 유사도 점수

## 2. 평가 질문 데이터 불러오기

평가 데이터에 다음 필드가 포함되어 있는지 확인한다.

| 필드 | 설명 |
| --- | --- |
| `question_id` | 질문 고유 번호 |
| `question` | 실제 검색에 사용할 질문 |
| `document_id` | 정답이 포함된 원본 문서 ID |
| `answer` | 실제 정답 |
| `answer_start` | 원문에서 정답이 시작되는 위치 |
| `is_answerable` | 문서 안에 정답이 있는지 여부 |

## 3. 질문 전처리

- [ ] 빈 질문 제거
- [ ] 중복 질문 확인 및 처리
- [ ] 검색에 사용할 질문 형식 통일
- [ ] 초기 평가에서는 `is_answerable=true`인 질문만 선별

## 4. 질문 임베딩 생성

- [ ] 문서 청크 임베딩에 사용한 것과 동일한 모델 사용
- [ ] 문서 청크와 동일한 전처리 및 정규화 설정 적용
- [ ] 질문별 임베딩 생성 시간 측정

## 5. Top-k 검색 실행

- [ ] 질문 임베딩으로 Chroma DB 검색
- [ ] `Top-1`, `Top-3`, `Top-5` 결과 확인
- [ ] 필요시 `Top-10`까지 확장

## 6. 검색 결과 저장

질문별 검색 결과에 다음 항목을 저장한다.

- `question_id`
- 검색 순위(`rank`)
- `chunk_id`
- `document_id`
- 청크 내용
- 거리 또는 유사도 점수
- 질문 임베딩 시간
- Vector DB 검색 시간

## 7. 정답 청크 포함 여부 확인

- [ ] 검색된 청크가 정답 청크인지 확인
- [ ] 정답 청크가 처음 등장한 순위 저장
- [ ] Top-k 안에서 정답을 찾지 못한 질문 별도 분리

정답 청크 판정 시 `document_id` 일치 여부뿐 아니라 `answer_start`가 검색된 청크의 원문 범위에 포함되는지도 함께 확인한다.

## 8. 검색 성능 기초 결과 정리

- [ ] Top-1·3·5별 정답 포함 여부
- [ ] 정답 청크 최초 등장 순위
- [ ] 질문별 임베딩 시간
- [ ] 질문별 Vector DB 검색 시간
- [ ] 질문별 전체 처리 시간
- [ ] 전체 평균 처리 시간

## 9. 평가 담당자에게 전달할 결과물

- [ ] Top-k 검색 결과 파일
- [ ] 질문별 정답 포함 여부
- [ ] 정답 최초 등장 순위
- [ ] 거리 또는 유사도 점수
- [ ] 질문별 임베딩 및 검색 시간
- [ ] 정답 미검색 질문 목록

### 권장 결과 파일

```text
outputs/
├── retrieval_results.csv
├── evaluation_summary.csv
└── retrieval_failures.csv
```

| 파일 | 내용 |
| --- | --- |
| `retrieval_results.csv` | 질문별 Top-k 검색 결과와 순위, 청크, 점수, 처리 시간 |
| `evaluation_summary.csv` | 질문별 Top-1·3·5 정답 포함 여부와 정답 최초 순위 |
| `retrieval_failures.csv` | Top-k에서 정답 청크를 찾지 못한 질문 목록 |

## 완료 기준

- Vector DB 로드 및 검색이 정상적으로 수행된다.
- 모든 평가 질문에 대한 Top-1·3·5 검색 결과가 저장된다.
- 정답 청크 포함 여부와 최초 등장 순위를 확인할 수 있다.
- 임베딩 시간, 검색 시간 및 전체 평균 처리 시간이 정리된다.
- 평가 담당자가 바로 활용할 수 있는 결과 파일을 전달한다.
