# 01_build_sample.py 설명

이 단계는 AIHub 원본 데이터에서 RAG 실험에 필요한 작은 샘플을 뽑습니다.

## 왜 샘플을 먼저 만드나?

AIHub 전체 데이터는 큽니다.

처음부터 전체 데이터를 임베딩하면 시간이 오래 걸리고, 문제가 생겼을 때 원인을 찾기 어렵습니다.

그래서 처음에는 작은 샘플만 사용합니다.

```text
context 200개
question/answer 30개
```

이 정도면 RAG 흐름을 공부하기에 충분합니다.

## 입력 데이터

기본 입력은 다음 파일입니다.

```text
Data/기계독해/기계독해분야/01.Normal.zip
```

또는 이미 압축을 풀었다면 다음 JSON 파일을 읽습니다.

```text
Data/기계독해/기계독해분야/01.Normal/ko_nia_normal_squad_all.json
```

zip을 직접 풀 필요는 없지만, 이미 풀어둔 상태여도 괜찮습니다.

## 출력 파일

이 스크립트는 두 파일을 만듭니다.

```text
Data/samples/documents.jsonl
Data/samples/eval_questions.csv
```

## documents.jsonl

`documents.jsonl`은 벡터DB에 넣을 문서 목록입니다.

여기에는 `context`만 들어갑니다.

예시:

```json
{"doc_id":"doc_0001","title":"15657","source":"5","text":"한국청소년단체협의회와 여성가족부는..."}
```

각 줄이 문서 하나입니다.

나중에 이 `text`를 청크로 나누고 임베딩합니다.

## eval_questions.csv

`eval_questions.csv`는 검색 실험을 채점하기 위한 질문과 정답 파일입니다.

예시:

```csv
question_id,doc_id,question,answer,title
c1_57059-1,doc_0001,서울과 충북 괴산에서 '국제청소년포럼'을 여는 곳은?,한국청소년단체협의회와 여성가족부,15657
```

여기서 `answer`는 벡터DB에 넣지 않습니다.

검색 결과가 맞았는지 확인하는 정답지로만 사용합니다.

## 실행 방법

```bash
python src/01_build_sample.py
```

샘플 크기를 바꾸고 싶으면 이렇게 실행합니다.

```bash
python src/01_build_sample.py --max-contexts 300 --max-questions 50
```
