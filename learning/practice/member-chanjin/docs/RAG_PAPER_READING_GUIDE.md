# RAG 논문 지식베이스 활용 가이드

이 앱에는 원문 PDF 전체가 아니라, 팀원들이 RAG 개념을 빠르게 이해할 수 있도록 정리한 **한국어 논문 요약 노트**가 들어 있습니다.

## 왜 원문 전체를 넣지 않았나?

1. 논문 PDF 전체를 넣으면 chunk 수가 급격히 늘어나 실습 앱이 느려집니다.
2. 팀원 과제 목적은 논문 암기가 아니라 RAG 핵심 구조와 trade-off 이해입니다.
3. RAG 챗봇이 더 잘 답하려면 원문 전체보다 잘 구조화된 요약 노트가 더 효과적일 때가 많습니다.

## 팀원 과제 확장

각 팀원은 논문 하나를 골라서 다음 형식으로 5분 발표하면 좋습니다.

1. 논문이 해결하려는 문제
2. 핵심 아이디어
3. 기존 RAG와 차이
4. 우리 프로젝트에 적용할 수 있는 부분
5. 구현하지 않더라도 대시보드 지표로 반영할 수 있는 부분
